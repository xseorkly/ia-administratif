Atelier 06 · Macros Excel · 90 min · en binôme

Je fais construire ma fenêtre de pilotage dans Excel

Le DAF veut que le classeur des achats s'analyse en un clic, sans nouveau logiciel. Vous allez faire écrire par l'IA une petite fenêtre qui s'ouvre dans Excel et qui fait trois choses : contrôler les données, comparer les dépenses au budget, lister les rappels du jour.

1 · La situation

Lundi 19 octobre 2026, LFI Marie-Curie de Valmont

Tout le suivi des achats tient dans un classeur Excel, Suivi-achats-2026 : les fournisseurs, 240 commandes, le budget des services et les échéances à surveiller. Tout se fait à la main. Le DAF, Patrice Aubertin, a écrit une note : il veut une fenêtre de pilotage qui s'ouvre avec le classeur.

Excel sait le faire avec ses macros (le langage VBA). L'IA peut écrire ce code, à condition que vous lui disiez précisément ce que vous voulez et quelles règles respecter. Et justement, certaines règles ne sont pas dans la note du DAF : elles sont dans des courriels reçus ce matin.

Protection des données. L'onglet Fournisseurs contient des noms, des adresses et des téléphones. Avant de donner le classeur à l'IA, faites-en une copie et pseudonymisez les colonnes Contact, Mail et Téléphone avec l'outil de l'atelier 00 (ou remplacez-les par des valeurs fictives). L'IA a seulement besoin de voir comment le classeur est organisé. Le code fonctionnera ensuite sur le vrai fichier, sur votre ordinateur.

3 · Votre mission · 90 min

Quatre étapes, dans l'ordre

Commencez par télécharger le dossier et le décompresser dans un dossier à vous. Ce que vous écrivez sur cette page reste sur votre appareil.

ÉTAPE 1 · SANS IA

Lire le dossier et noter les règles

15:00

Lisez la note du DAF (une page), puis les cinq courriels. Ils contiennent des règles que l'outil devra respecter. Répondez ci-dessous : vos réponses seront ajoutées automatiquement au prompt de l'étape 3.

C'est terminé quand vous avez répondu aux questions 1 à 4 et corrigé la date dans le classeur.
ÉTAPE 2 · AVEC L'IA, SANS CODE

Préparer le classeur et le faire analyser

15:00
  1. Ouvrez Suivi-achats-2026.xlsx et faites Fichier › Enregistrer sous, type « Classeur Excel (prenant en charge les macros) (*.xlsm) ». C'est ce fichier .xlsm qui recevra l'outil.
  2. Faites une copie pseudonymisée pour l'IA (colonnes Contact, Mail, Téléphone de l'onglet Fournisseurs).
  3. Dans Claude ou ChatGPT, ouvrez une nouvelle conversation, joignez la copie pseudonymisée et la note du DAF, puis envoyez ce prompt :
Je suis assistante de direction dans un lycée. Je te joins le classeur de suivi des achats (les contacts des fournisseurs sont pseudonymisés) et la note du DAF.

Avant d'écrire du code, aide-moi à connaître ce classeur :
1. Pour chaque onglet : le nom exact des colonnes et le nombre de lignes. Compte avec du code, pas à l'œil.
2. La liste des problèmes dans les données (onglet, ligne, problème).

Réponds simplement, sans jargon. N'écris aucun code pour l'instant.

Lisez la réponse. Vérifiez vous-même deux problèmes dans Excel : sont-ils vraiment là ?

C'est terminé quand l'IA vous a décrit les onglets et vous avez vérifié deux problèmes à la main.

Faire écrire la fenêtre et l'installer

25:00

A. Envoyez le prompt de construction, dans la même conversation. Il est déjà écrit : les lignes en vert sont vos réponses de l'étape 1. Relisez-le avant de l'envoyer.

Préparer les rappels en brouillons Outlook

Un 4e bouton qui crée un brouillon Outlook par rappel, avec le modèle « Rappel échéance » de l'onglet Modèles. Pensez à demander : brouillons seulement (jamais d'envoi), un onglet Journal pour ne jamais préparer deux fois le même rappel, et la personne en copie. Relisez le courriel de Julien Castel : quelle adresse utiliser pour les essais ? Quelle version d'Outlook faut-il ?


Comparer les devis

Un bouton qui compare les devis d'un même besoin (prix, délai, garantie, note du fournisseur). Attention : certains devis ne sont pas en euros. Le courriel du DAF et le dossier de contexte disent quel taux utiliser. Demandez que le taux utilisé soit affiché.


Créer une copie pseudonymisée en un clic

Un bouton qui enregistre une copie du classeur où les contacts, mails et téléphones sont remplacés par des codes, avec la table de correspondance dans un fichier séparé.








Coups de pouce


Vous êtes bloqué·e ?


La fenêtre ne s'ouvre pas

  • Le fichier est-il bien en .xlsm ? Un .xlsx perd les macros.
    • 

  • Avez-vous cliqué sur Activer le contenu ? Si un bandeau rouge parle de « risque de sécurité » : fermez Excel, clic droit sur le fichier › Propriétés › cochez Débloquer.
    • 

  • Le bloc C est-il bien collé dans ThisWorkbook (et pas dans le module) ?


Un message d'erreur s'affiche

Ne cherchez pas à comprendre le code. Notez le message exact (avec son numéro) et, s'il y en a une, la ligne surlignée en jaune. Cliquez sur Fin (ou sur le carré bleu ■ dans l'éditeur), puis envoyez le message de correction à l'IA.


Le message parle d'« accès au projet Visual Basic »

Le code essaie de se modifier lui-même, ce que les ordinateurs du service n'autorisent pas. Rappelez à l'IA la contrainte : « la fenêtre est une UserForm vide nommée frmPilotage, c'est ton code qui crée les boutons à l'ouverture ».


La fenêtre s'ouvre, mais elle est vide

Vérifiez le nom de la UserForm : frmPilotage, exactement. Vérifiez que le bloc A est collé dans le code de la fenêtre (clic droit › Code), et pas dans le module.


Je n'ai pas le même nombre de rappels que l'outil

  • Quelle date l'outil affiche-t-il en haut de la fenêtre ?
    • 

  • Avez-vous corrigé la date de la question 4 dans le classeur ?
    • 

  • Reprenez chaque rappel en trop : une des règles de votre fiche l'interdit-elle ? Est-elle bien dans le prompt ?


L'IA a tout réécrit et ce qui marchait est cassé

Recollez l'ancien bloc, puis demandez une correction ciblée : « Ne modifie que le bouton Rappels du jour ; ne touche pas au reste. »


Je n'ai pas Excel sous Windows

Les macros de fenêtre ne fonctionnent pas sur Mac ni dans Excel en ligne. Travaillez en binôme sur un ordinateur Windows.








Glossaire


Les mots de l'atelier




Macro / VBA
Petit programme enregistré dans un classeur Excel. VBA est le langage de ces programmes.


Classeur .xlsm
Format de classeur qui garde les macros. Un .xlsx les perd.


Éditeur VBA
La fenêtre d'Excel où l'on colle le code (Alt+F11).


UserForm
Une fenêtre (boîte de dialogue) qui s'ouvre par-dessus le classeur, avec des boutons.


Module
Un emplacement pour du code, dans l'éditeur VBA.


Date simulée
La date du 19/10/2026, inscrite dans l'onglet Paramètres, pour que tout le monde obtienne les mêmes rappels.


Pseudonymisation
Remplacer les données personnelles par des codes, en gardant la correspondance à part (atelier 00).
