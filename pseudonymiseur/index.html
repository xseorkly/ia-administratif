Le pseudonymiseur hors ligne

Un petit logiciel qui masque les noms, les dates, les adresses et les numéros d'un fichier Excel ou Word avant de le confier à une IA, puis qui remet les vraies informations dans le travail rendu par l'IA. Il tient dans un seul fichier, s'ouvre dans le navigateur et n'envoie rien sur Internet.

Ouvrir le logiciel ↓↧ Télécharger le logiciel (1 Mo)
Pour quiToute personne qui veut faire travailler une IA sur un fichier contenant des personnes.
FichiersExcel (.xlsx, .xls, .ods, .csv) et Word (.docx).
InstallationAucune : un fichier HTML à ouvrir avec Chrome, Edge ou Firefox.
ConnexionAucune donnée ne quitte l'ordinateur. Fonctionne Wi-Fi coupé.
À quoi il sert

Faire travailler l'IA sans lui donner les noms.

Vous voulez qu'une IA prépare un courrier aux familles, trie une liste d'élèves ou résume un compte rendu. Le problème : le fichier contient des noms, des dates de naissance, des courriels, des téléphones. Le pseudonymiseur remplace chacune de ces informations par un code, par exemple [NOM_001]. L'IA travaille sur les codes. Vous seule gardez la correspondance entre les codes et les vraies informations.

Remarquez que « Hugo » dans les observations devient le même code que dans la colonne Prénom. C'est voulu : l'IA comprend qu'il s'agit de la même personne et peut raisonner juste, sans jamais savoir qui elle est.

Pseudonymiser n'est pas anonymiser. Pseudonymiser, c'est remplacer les noms par des codes en gardant de quoi revenir en arrière : c'est ce que fait ce logiciel. Anonymiser, c'est rendre la personne impossible à retrouver, définitivement. Un fichier pseudonymisé reste soumis au RGPD, et le contexte peut suffire à reconnaître quelqu'un (« la seule élève de 4e arrivée de Tokyo en janvier »). Relisez toujours le fichier avant de l'envoyer.
Le cycle complet

Quatre temps, un aller et un retour.

Le logiciel est organisé en onglets qui suivent exactement ces étapes.

Ma clé

Le logiciel génère une clé secrète (un mot de passe de 20 caractères). Vous la notez et la rangez à part.

Masquer les données

Vous déposez le fichier, vous vérifiez ce qui sera codé, vous téléchargez la copie _PSEUDO et la sauvegarde .json.

Travailler avec l'IA

Vous donnez à l'IA uniquement la copie masquée, avec la consigne que le logiciel a préparée.

Retrouver mon fichier

Clé + sauvegarde JSON + fichier rendu par l'IA : un bouton remet les vrais noms et télécharge un fichier _REIDENTIFIE.

🔒 Reste sur votre ordinateur

  • le fichier d'origine ;
  • la clé secrète (jamais dans le même dossier que le JSON) ;
  • la sauvegarde JSON des correspondances.

↗ Part vers l'IA

  • la copie _PSEUDO, après relecture ;
  • la consigne qui demande de garder les codes intacts ;
  • votre demande (« rédige un courrier pour… »).
Comment il fonctionne vraiment

Sous le capot.

Pas besoin de savoir programmer pour l'utiliser. Mais pour lui faire confiance, il faut savoir ce qu'il fait réellement de vos fichiers. Choisissez un thème.

Tout se passe dans le navigateur

Le logiciel est un seul fichier HTML d'environ 1 Mo. Il contient tout ce dont il a besoin, y compris deux bibliothèques libres qui savent lire et écrire les fichiers Office : SheetJS pour Excel et JSZip pour ouvrir l'intérieur des fichiers .xlsx et .docx (qui sont en réalité des dossiers compressés).

  • Quand vous « déposez » un fichier, il n'est pas envoyé : le navigateur le lit directement depuis votre disque, en mémoire.
  • La page contient une règle de sécurité (Content-Security-Policy avec connect-src 'none') qui interdit au navigateur toute connexion réseau depuis cette page. Même si quelqu'un voulait lui faire envoyer vos données, le navigateur refuserait.
  • Le badge en haut du logiciel affiche l'état : « Hors ligne » ou « Connecté, mais aucune donnée envoyée ».
  • La preuve la plus simple : coupez le Wi-Fi, tout continue de fonctionner.
  • Les fichiers produits (copie masquée, JSON, fichier restauré) sont créés dans le navigateur et arrivent dans votre dossier Téléchargements.
Conséquence pratique : vous pouvez copier le fichier sur une clé USB ou dans un dossier partagé du service, il fonctionne partout, sans installation ni compte.

Un nom devient un jeton

Chaque information à masquer est remplacée par un jeton : une catégorie en majuscules et un numéro à trois chiffres, entre crochets.

[NOM_001][PRENOM_001][PERSONNE_001][DATE_001][EMAIL_001][TEL_001][ADRESSE_001][LIEU_001][ID_001][AUTRE_001]

Trois règles rendent ces jetons utiles à l'IA :

  • Une même valeur donne toujours le même jeton. « MARTIN », « Martin » ou « martin » avec un espace de trop : c'est la même personne, donc [NOM_001] partout. L'IA peut croiser les informations.
  • Les numéros continuent. Si vous masquez un deuxième fichier dans la même séance, les nouveaux noms prennent la suite ([NOM_007], [NOM_008]…), et les noms déjà connus gardent leur code.
  • Le logiciel retient chaque correspondance dans une table (jeton ↔ vraie valeur), visible dans l'onglet « 1. Ma clé », valeurs floutées par défaut.

Le logiciel repère aussi, dans le texte libre (observations, commentaires, corps d'un courrier), trois types d'informations grâce à leur forme :

Courrielstout ce qui ressemble à quelquechose@domaine.fr
Téléphonesnuméros français (06 12 34 56 78, 01.23.45.67.89) et internationaux (+43 …)
Datesau format jj/mm/aaaa (option à cocher, car toutes les dates ne sont pas personnelles)

Enfin, il prépare une consigne à coller dans l'IA avec le fichier : garder chaque jeton exactement tel quel, ne pas en inventer, ne pas essayer de deviner les vraies valeurs. Il ne vous reste qu'à écrire votre demande à la suite de « Tâche : ».

Dans un classeur Excel

Le logiciel devine, vous vérifiez. À l'ouverture, il cherche la ligne des titres (la première qui contient au moins deux cellules remplies) et lit chaque titre de colonne :

Nom, Prénomcochés et classés en NOM / PRENOM
Date de naissance, né(e) lecochés en DATE, avec en option une colonne Âge calculée (utile si l'IA doit raisonner sur l'âge sans connaître la date)
Responsable, parent, père, mèrecochés en PERSONNE
Mail, téléphone, adresse, INE, matriculecochés dans leur catégorie
Santé, PAI, PPS, allergie, traitement, bourse, social, religion…marqués en rouge « supprimer » : ces données ne doivent pas partir du tout, même codées
  • Feuilles : vous cochez les feuilles à traiter ; chacune garde ses propres réglages.
  • Sens du tableau : si les titres sont dans la première colonne (une fiche par colonne), le logiciel le détecte et travaille en lignes.
  • Repérage par la mise en forme (.xlsx seulement) : vous pouvez aussi masquer les cellules, ou les mots à l'intérieur d'une cellule, écrits en gras, en couleur, souligné… selon une règle que vous choisissez.
  • Les autres colonnes : une fois les noms connus, le logiciel les cherche aussi dans les observations et les remplace par le même jeton (option cochée par défaut).

Pourquoi le classeur garde sa présentation

Un fichier .xlsx est un dossier compressé qui contient des fichiers XML : un par feuille, plus un « dictionnaire » de tous les textes du classeur. Au lieu de reconstruire le classeur (ce qui ferait perdre couleurs, largeurs, tableaux), le logiciel modifie uniquement les cellules concernées dans ces XML. Il supprime aussi l'ancien dictionnaire des textes, sinon les vrais noms y resteraient cachés à l'intérieur du fichier. Les colonnes à supprimer sont vidées sur place, sans décaler les autres, pour ne pas casser les formules.

Les feuilles non cochées, les commentaires (notes) de cellule, les liens hypertextes, les formules, les graphiques, les noms de plages et les propriétés du fichier ne sont pas vérifiés. Ouvrez la copie _PSEUDO et parcourez-la avant tout envoi.

Dans un document Word

Dans un courrier, impossible de deviner seul ce qui est un nom. Le principe est donc inverse : c'est vous qui marquez les informations à masquer, avec une mise en forme repère. Par défaut : gras, italique, souligné, bleu. La règle est réglable (couleur rouge ou verte, taille de police, « toutes les conditions » ou « au moins une »).

  • Le logiciel ouvre le .docx, lit le corps du texte et les en-têtes, pieds de page, notes de bas de page et commentaires.
  • Il liste les passages repérés, devine leur catégorie (courriel, date, téléphone, numéro, personne) et vous laisse décocher ou corriger.
  • Il remplace les passages par leurs jetons, puis, en option, toutes les autres occurrences du même nom, même non mises en forme.
  • Il code aussi les adresses cachées dans les liens « mailto: » et efface les propriétés du fichier (auteur, dernier modificateur, titre, société…), qui trahissent souvent un nom.
Limites : seule la mise en forme appliquée directement au texte est repérée (pas celle d'un style de paragraphe) ; les zones de texte et les images ne sont pas analysées ; l'ancien format .doc n'est pas lu (« Enregistrer sous » .docx d'abord).

La clé et la sauvegarde JSON

La table des correspondances est ce qui permet de revenir en arrière. C'est donc aussi la donnée la plus sensible : elle contient tous les vrais noms. Le logiciel l'enregistre dans un petit fichier table-correspondance-AAAAMMJJ-HHMM.json, chiffré.

La clé20 caractères tirés au hasard par le navigateur, en 4 groupes de 5 (sans les caractères qui se confondent : 0/O, 1/l/I). Vous pouvez aussi saisir votre propre clé, 12 caractères minimum.
Le chiffrementAES-256-GCM, la norme utilisée par les banques et les messageries sécurisées.
La dérivationLa clé est passée 310 000 fois dans une fonction de hachage (PBKDF2-SHA-256) avec un « sel » aléatoire. Résultat : essayer des milliers de clés au hasard devient extrêmement lent.
Le contrôleSi la clé est fausse ou le fichier abîmé, le logiciel refuse de l'ouvrir : il ne restitue jamais de données fausses.
Sans la clé, personne ne peut rien retrouver, vous comprise. Ni le formateur, ni le logiciel n'ont de « porte de secours ». Rangez la clé dans un gestionnaire de mots de passe ou sur papier, jamais dans le même dossier que le JSON, et ne donnez jamais ni l'un ni l'autre à l'IA.

Le logiciel vous prévient tant que la table n'est pas sauvegardée, et vous demande confirmation si vous fermez la page avant.

Remettre les vrais noms

Dans l'onglet « 3. Retrouver mon fichier », il faut trois éléments : la clé, la sauvegarde JSON et le fichier rendu par l'IA. Le fichier d'origine n'est pas nécessaire.

  • Le logiciel déchiffre le JSON avec la clé, puis parcourt le fichier de l'IA à la recherche de jetons.
  • Formats acceptés : Excel (.xlsx, .xlsm, .xls, .ods, .csv), Word (.docx) et texte (.txt, .md). Le résultat est téléchargé sous le nom …_REIDENTIFIE.
  • Il est tolérant : il retrouve [NOM_001] même si l'IA a écrit NOM_001 sans crochets ou NOM_1.
  • Une cellule Excel qui ne contient qu'un jeton de date redevient une vraie date.
  • Si l'IA a inventé un jeton qui n'existe pas dans la table ([NOM_099]), il est laissé tel quel et signalé : c'est un indice que l'IA a mal travaillé.
  • Pour une réponse de l'IA copiée dans la conversation, une zone permet de coller le texte et de récupérer la version avec les vrais noms.
Les bons réflexes

Un outil, pas une autorisation.

Avant

Vérifier ce qui est coché

Les cases sont pré-cochées par devinette. Une colonne mal nommée (« Contact », « Référent ») peut échapper au repérage automatique.

Pendant

Relire la copie masquée

Ouvrez le fichier _PSEUDO avant de l'envoyer : un nom dans un titre, une formule ou une feuille non cochée peut rester visible.

Toujours

Pas de données sensibles

Santé, vie familiale, difficultés sociales : même pseudonymisées, elles ne partent pas vers une IA sans l'accord du référent RGPD de l'établissement.
